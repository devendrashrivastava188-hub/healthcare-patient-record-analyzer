#Healthcare Patient Record Analyzer -
a python project for practicing basic using fictional healthcare patient records.

##Features - 
-stores fictional patient records
- counts total patients
-calculates average age
-searches for a patient using patient Id
-displays the patient's basic record
-hendles an id that is not found

##Technologies Used -
-python 3
-lists
-dictionaries
-loops
-conditions
-basic data analysis

##How it works - 
the program stores fictional patient records and performs some simple analysis.
it shows the total number of patients and calculates the average age.
the user can also enter a patient id to search for a particular record.

##Challenges & Mistakes I Faced-
is project ko banate waqt mujhe kuch **Name-error (Capitalization & Typo)** issues mile.

* **Case sensitivity (Capitalization):** Variable name me 'patients' (small letter) likh diya tha jabki define 'Patients' (capital P) kiya tha,
Python case-sensitive hota hai isliye 'Name-error' aaya.

* **Typo Errors in Variable Names:**'average_age' ki jagah typo karke 'averange_age likh diya tha.

i made this project to practice python data handling and learn how simple programming can be used for healthcare-related data.
